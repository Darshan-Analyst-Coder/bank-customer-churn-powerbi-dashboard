# Bank Customer Churn Analysis Dashboard (Power BI)

## Project Overview

This project analyzes customer churn data using Power BI to identify patterns and factors that influence customer retention. The dashboard provides interactive visual insights into customer behavior, helping understand why customers leave the bank and which groups are more likely to churn.

The dataset includes customer demographic details, account information, credit scores, balances, and activity status. Using DAX measures and visual analytics, the project highlights important business metrics and trends.

---

## Objectives

* Analyze customer churn patterns
* Identify high-risk customer segments
* Compare churn rate across gender and geography
* Provide actionable insights for improving customer retention
* Demonstrate Power BI and DAX skills

---

## Tools & Technologies Used

* Power BI
* DAX (Data Analysis Expressions)
* Excel
* Data Visualization
* Data Modeling

---

## Dashboard Features

* KPI Cards (Churn Rate, Total Customers, Churned Customers, Avg Balance)
* Churn Rate by Gender
* Customer Activity Status (Active vs Inactive)
* Retained vs Churned Customers by Geography
* Average Credit Score by Gender
* Interactive Country Slicer

---

## Key Insights

* Overall churn rate is approximately **20.4%**
* Female customers have a higher churn rate compared to male customers
* Nearly half of customers are inactive, indicating potential churn risk
* France has the highest number of customers among the available countries
* Customer segmentation helps identify retention opportunities
